1.2 Storage Specifications

- Type: Network-attached NVMe SSD
- Capacity: 100 GB to 64 TB per volume
- IOPS: Up to 250,000 (read), 125,000 (write)
- Throughput: Up to 4 GB/s per volume
- Snapshots: Incremental, up to 10,000 per volume
- Replication: Synchronous to 2 replicas, cross-zone optional
- Encryption: AES-256 at rest, keys managed by ACME or CMK
- Pricing: $0.12/GB/month (standard SSD), $0.04/GB/month (HDD)
- Durability: 99.999% annual

Object Storage (ACP Object):
- Compatibility: S3 API compatible
- Maximum object size: 5 TB
- Maximum bucket size: Unlimited (quotas apply per tier)
- Storage classes:
  * Standard: 99.99% availability, $0.023/GB/month

- Cross-region replication: Available, $0.02/GB transfer cost

File Storage (ACP File):
- Protocol: NFS v4.1 and SMB 3.0
- Maximum file system size: 100 TB
- Throughput: Up to 10 GB/s per file system
- IOPS: Up to 500,000 per file system
- Pricing: $0.16/GB/month (standard), $0.40/GB/month (high-performance)

SECTION 2: API SPECIFICATIONS

2.1 ACME REST API

Base URL: https://api.acme-corp.example.com/v4
Current API Version: v4 (released January 2025, EOL: January 2028)

Authentication:
- Type: Bearer token (JWT) or API Key
- Token expiry: Bearer tokens expire in 24 hours, refresh valid for 30 days
- API key rotation: Every 90 days recommended, enforced for Enterprise

Rate Limits by Tier:
- Starter: 100 requests/minute, 10,000/day
- Professional: 1,000 requests/minute, 500,000/day
- Enterprise: 10,000 requests/minute, unlimited/day

Standard HTTP Status Codes:
- 200 OK: Successful operation
- 201 Created: Resource created successfully
- 400 Bad Request: Malformed request, check error details
- 401 Unauthorized: Missing or invalid authentication
- 403 Forbidden: Insufficient permissions
- 429 Too Many Requests: Rate limit exceeded
- 500 Internal Server Error: ACME platform error

2.2 ACME SDK and Client Libraries
